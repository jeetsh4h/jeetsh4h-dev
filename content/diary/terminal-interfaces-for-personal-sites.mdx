A terminal surface works best when it is a second way into the same content, not the only way to understand the site.

## Commands as links

Commands should resolve to useful destinations quickly. A portfolio terminal can expose terse aliases, but the output still needs normal links, readable hierarchy, and predictable escape routes back to the page.

| Command      | Purpose        |
| ------------ | -------------- |
| `experience` | Work history   |
| `projects`   | Project links  |
| `diary`      | Recent writing |

## Keep the page readable

The regular homepage still matters. It should remain scannable on its own, while the terminal gives people who enjoy command-driven navigation a richer path through the same material.
