## Local Development

```bash
pnpm install
pnpm dev
```

## CV Build

Requires a local LaTeX installation with `latexmk`.

```bash
pnpm cv:build
```

The generated PDF is copied to `public/cv.pdf` for local preview.

## Checks

```bash
pnpm lint
pnpm test
pnpm build
pnpm verify
```
